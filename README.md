# skytune

Автотюн (коррекция высоты голоса) в формате **VST3**, современный анимированный интерфейс, пресеты, установщик.
Сделано tripleskyluv corp.

## Как получить плагин и установщик (Windows, без компиляторов)

1. Создайте на GitHub новый репозиторий (например `skytune`) и загрузите в него **всё содержимое этой папки**
   (папки `Source`, `tests`, `installer` и файлы перетаскивайте мышкой в окно браузера).
   Скрытую папку `.github` GitHub при перетаскивании не принимает: создайте файл вручную через
   *Add file → Create new file*, имя `.github/workflows/build.yml`, и вставьте туда содержимое из этого архива.
2. Откройте вкладку **Actions**. Сборка стартует сама, первый раз около 10–15 минут.
3. В разделе **Artifacts** будут два архива:
   - `skytune-setup`: внутри `skytune-setup.exe`, обычный установщик (рекомендуется);
   - `skytune-VST3-Windows`: папка `skytune.vst3`, которую можно положить вручную в
     `C:\Program Files\Common Files\VST3\`.
4. FL Studio: **Options → Manage plugins → Find installed plugins**, затем добавьте skytune на дорожку с вокалом.

Если сборка красная, пришлите последние 30–40 строк лога упавшего шага.

## Как это работает

1. **Детектор высоты** (метод МакЛеода, NSDF): находит основную частоту голоса с точностью около 1 цента,
   отличает пение от шумов и согласных.
2. **Коррекция**: выбирает ближайшую разрешённую ноту (гамма, свои ноты или ноты MIDI) с гистерезисом,
   считает, на сколько нужно сдвинуть высоту.
3. **PSOLA-ресинтез**: звук режется на «зёрна» по периодам голоса и собирается заново с нужным периодом,
   поэтому тембр (форманты) остаётся на месте, а высота меняется. Шипящие и дыхание проходят без изменений.

Коррекция применяется ровно к тому звуку, по которому измерена высота (плагин «смотрит вперёд»),
поэтому в начале ноты нет запаздывания. Цена: постоянная задержка около 45 мс, FL Studio компенсирует её сама.

## Параметры

| Параметр | Что делает |
|---|---|
| Retune speed | скорость подстройки: 0 = HARD (робот, эффект T-Pain), 10–30 мс = современный «трэп», 60–150 мс = естественно |
| Amount | сила коррекции (при 80% остаётся небольшая «живость») |
| Humanize | сколько собственного вибрато певца сохранить |
| Formant | сдвиг тембра ±5 полутонов (не меняя ноту): «мультяшный» или «басовый» голос |
| Vibrato / Vib rate | добавить искусственное вибрато (глубина в центах, скорость в Гц) |
| Reference | эталонная частота ноты A4 (440 Гц) |
| Key + Scale | тональность и гамма; **Chromatic** = любая нота |
| Notes | клавиши: нажмите, чтобы включить/выключить ноту (гамма переключится на Custom) |
| Source: MIDI | голос подтягивается к нотам, которые вы играете по MIDI (если на плагин подан MIDI) |
| Mix / Output | баланс оригинала и обработки, выходная громкость |

## Интерфейс

- Окно **высоты тона**: пианино слева, подсвечены ноты гаммы; тонкая линия: что спел вокалист, яркая светящаяся: что получилось.
  Слева сверху крупно: распознанная и целевая ноты.
- **Три цветовые темы** (точки справа сверху), выбор запоминается.
- Ручки плавно догоняют значения, числа «считают» вместе с ними, при смене пресета всё красиво переезжает.

## Пресеты

Стрелки `‹ ›` листают, клик по названию открывает меню (12 заводских + ваши). **SAVE**: введите имя, Enter.
Пресеты лежат в `C:\Users\<вы>\AppData\Roaming\skytune\Presets\*.skytpreset`. Звёздочка `*` у названия: параметры
изменены после загрузки пресета. Выбранный пресет сохраняется вместе с проектом.

## Советы

- Для тюна «как у артистов»: Retune speed 0–10 мс, Humanize 0, **подходящая тональность и гамма** (а не Chromatic).
- Для незаметной коррекции: Retune 80–150 мс, Amount 70–90%, Humanize 60–80%.
- Работает только с одним голосом (монофонично): аккорды, хоры и целые миксы тюнить нельзя.
- Чем чище запись (без шума, реверба и эха), тем точнее детектор. Ставьте плагин до реверба.

## Проверка алгоритма (опционально)

```
cd tests
g++ -std=c++17 -O2 -I../Source/dsp dsp_tests.cpp -o dsp_tests && ./dsp_tests
g++ -std=c++17 -O2 -I../Source/dsp render_demo.cpp -o render_demo && ./render_demo demo.wav pitch.csv
```

Тесты проверяют детектор (90–880 Гц, три частоты дискретизации), точность попадания в ноты, гаммы,
скорость, вибрато и Humanize, громкость, форманты, проход шумов и устойчивость на случайных параметрах.

## Лицензия JUCE

JUCE распространяется по AGPLv3 или по коммерческой лицензии. Для личного использования это не важно; при публикации
плагина нужна коммерческая лицензия JUCE или открытые исходники.
